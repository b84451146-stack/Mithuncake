# ASHIF - ASCII AK-47 animation

Animated ASCII art: an AK-47 firing with muzzle flash, recoil, shell casings,
bullets and sparks that light up the name **ASHIF** letter by letter.

- `index.html` - open in a browser (or enable GitHub Pages: Settings > Pages > main branch)
- `animation.py` - terminal version, needs a 100+ column window: `python3 animation.py`
